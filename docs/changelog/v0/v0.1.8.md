## Overview

Version 0.1.8 stops the skipped pull-request mirror job from satisfying the `✅ Required PR Check` ruleset gate and bumps `@cldmv/vitest-runner`. It shares its title with 0.1.7 ("adopt the shared CLDMV fix-headers config…") because the release title is taken from one of the bundled PRs, but the fix-headers work shipped in 0.1.7. ## 🔧 CI & tooling

### Stop the skipped PR-run mirror from satisfying Required PR Check ([#39](https://github.com/CLDMV/jsonv-vscode/pull/39))

On an in-repo feature PR the `pull_request` run skipped the `required-check` job in `ci.yml` (the push run owns the status), but a skipped job still posts a check run under its name, and GitHub treats a skipped required check as passing. A PR could therefore become mergeable, or have auto-merge enabled, before the push run's tests had finished (incident: [CLDMV/slothlet#553](https://github.com/CLDMV/slothlet/issues/553)). The job's `name:` is now an expression, so the skipped job no longer reports under `✅ Required PR Check`, while every path that runs still does.
