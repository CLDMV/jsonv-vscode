# jsonv-vscode v0.1.3 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

Version 0.1.3 moves the repository's release and feature-PR workflows onto the current thin-caller templates and picks up a patched `brace-expansion` in the lockfile. The release title only mentions the dependency bump, but the larger part of the diff is the workflow change. No extension code changed.

---

## 🔧 CI & tooling

### Thin v4 callers for the release and feature-PR workflows ([#9](https://github.com/CLDMV/jsonv-vscode/pull/9))

`feature-pr.yml`, `next-release.yml` and `hotfixes-release.yml` were each rewritten from a long inline job definition (about 500 lines removed across the three) to a short caller of the matching reusable in `CLDMV/.github` (`workflow-feature-pr.yml`, `workflow-next-release.yml`, `workflow-hotfixes-release.yml`, all `@v4`). The triggers and the branch-prefix list stay local; the logic lives in the reusables, so fixes arrive by bumping the pin.

The callers also pass `BOT_NAME` and `BOT_EMAIL` (from `CLDMV_BOT_NAME` and `CLDMV_BOT_EMAIL`), so bot-authored commits and PRs are recognised as a bot rather than listed as contributors.

---

## 🔧 Dependencies

- Bump `brace-expansion` from 1.1.12 to 1.1.18 ([#8](https://github.com/CLDMV/jsonv-vscode/pull/8)). It is a dev-only transitive dependency of the packaging toolchain; only the lockfile changed and `package.json` ranges are untouched. It affects the repository's own CI and local installs, not the packaged extension.
