# jsonv-vscode v0.1.11 Changelog

**Release Date**: October 2026
**Release Type**: Patch
**Branch**: `release/0.1.11`

---

## Overview

A dev-dependency patch for the test toolchain: `@cldmv/vitest-runner` 1.5.1 → 1.5.3 ([#49](https://github.com/CLDMV/jsonv-vscode/pull/49)) and `vitest` 5.0.2 → 5.0.3 ([#48](https://github.com/CLDMV/jsonv-vscode/pull/48)). Neither is part of the packaged extension. The files the extension ships, which are the TextMate grammar (`syntaxes/jsonv.tmLanguage.json`), `language-configuration.json` and the two icons, are exactly as in [v0.1.10](./v0.1.10.md).

Two things in the VSIX do differ, neither a behaviour change: `package.json`, which every extension package includes, carries the new version and the two raised `devDependencies` ranges, and the README shown on the marketplace page has the updated What's New section.

The toolchain bump has one consequence for contributors. `@cldmv/vitest-runner` 1.5.3 raised its own `engines.node` from `>=20.19.0` to `>=22.12.0`, so running the tests now needs Node.js 22.12 or later. The extension has no `engines.node` of its own (only `engines.vscode`, which stays `^1.88.0`), and users of the extension are not affected.

---

## 🔧 Dependencies

Both are development dependencies and both ranges were raised in `package.json`; the lockfile resolves to the new versions.

- **`@cldmv/vitest-runner` `^1.5.1` → `^1.5.3`** ([#49](https://github.com/CLDMV/jsonv-vscode/pull/49)), resolved 1.5.1 → 1.5.3. Version 1.5.2 moved the runner's own `chalk` dependency from 5.6.2 to 6.0.1, which requires Node.js 22 or later; the lockfile now carries a single `chalk` 6.0.1 and the runner's nested 5.6.2 copy is gone. Version 1.5.3 raised the runner's `engines.node` to `>=22.12.0`, changed its CommonJS entry to fail with a clear `ERR_REQUIRE_ESM` message on a Node.js without `require(esm)`, and relicensed the runner under Apache-2.0.
- **`vitest` `^5.0.2` → `^5.0.3`** ([#48](https://github.com/CLDMV/jsonv-vscode/pull/48)), resolved 5.0.2 → 5.0.3, with `@vitest/mocker` and `@vitest/spy` at 5.0.3. `vite` 8.3.1 → 8.3.2, `rolldown` 1.2.11 → 1.2.12 (with its platform bindings), `@oxc-project/types` 0.151.0 → 0.152.0 and `source-map-js` 1.2.1 → 1.2.2 moved with them in the lockfile. `why-is-node-running` goes 3.2.2 → 3.2.1 because vitest 5.0.3 pins that exact version.

No dependency of the extension itself changed: it has no runtime dependencies, and `@vscode/vsce`, `vscode-textmate`, `vscode-oniguruma`, `@cldmv/configs` and `@cldmv/fix-headers` are unchanged.
