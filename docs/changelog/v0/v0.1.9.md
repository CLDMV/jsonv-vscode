# jsonv-vscode v0.1.9 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Version 0.1.9 follows up on the 0.1.8 required-check fix: the mirror job now always runs instead of being skipped. Only `ci.yml` and the version number changed; no extension code changed.

---

## 🔧 CI & tooling

### Run the in-repo PR mirror job instead of skipping it ([#41](https://github.com/CLDMV/jsonv-vscode/pull/41))

The conditional job name introduced in 0.1.8 did not work as intended: GitHub does not evaluate the `name:` of a skipped job, so the skipped job showed raw expression text. The `required-check` job now uses `if: always()` and never skips. On an in-repo feature PR it reports under `⏭️ Required PR Check (reported by the push run)` and exits as a no-op (controlled by an `OWNS_STATUS` environment value), while every path that owns the status (push events, fork PRs, and the `next` and `hotfixes` release PRs) reports `✅ Required PR Check` and mirrors the CI result as before.
