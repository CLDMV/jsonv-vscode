# jsonv-vscode v0.1.7 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Version 0.1.7 adopts the shared CLDMV `fix-headers` configuration and stamps a uniform comment header onto source, test, config and workflow files. The workflow-file changes in this release are comment headers only; the v4.29.2 template sync had already shipped in [v0.1.6](./v0.1.6.md). The shipped extension (grammar, language configuration, icons) is unchanged, and no runtime code changed.

---

## 🔧 CI & tooling

### Shared `fix-headers` config and uniform file headers ([#36](https://github.com/CLDMV/jsonv-vscode/pull/36))

- Add `@cldmv/fix-headers` (`^2.1.1`) and `@cldmv/configs` (`^1.2.0`) as dev dependencies, a `fix:headers` npm script (`fix-headers --config .configs/fix-headers.json`) and `.configs/fix-headers.json`, which extends `@cldmv/configs/fix-headers.json`.
- Stamp the standard header (`@Project`, `@Filename`, `@Date`, `@Author`, `@Email`, `@Last modified by`, `@Last modified time`, `@Copyright`) into the workflow files (`#` comments), `.github/dependabot.yml`, `.configs/vitest.config.mjs`, the test files and helpers, and `tests/run-vitest.mjs`. Existing partial headers were normalised to the same shape.
- The `.jsonv` test fixtures received the same header as a `/** ... */` block comment at the top of the file. The test files themselves changed by the header comment only.

---

## 🔧 Dependencies

- Add `@cldmv/fix-headers` and `@cldmv/configs` (plus the transitive `ignore` 7.0.12). All are dev dependencies and only affect the repository's own tooling; nothing changes for people installing the extension.
