# jsonv-vscode v0.1.5 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

Version 0.1.5 updates the Node.js version defaults in the CI and publish workflows to match vitest 5's real requirements. Only two workflow files and the version number changed; no extension code changed.

---

## 🔧 CI & tooling

### Node CI matrix for vitest 5 ([#13](https://github.com/CLDMV/jsonv-vscode/pull/13))

In `ci.yml` the `min_node_version` default moves from `20` to `22.12.0` (the vitest 5 floor) and `max_node_major` from `22` to `26`. In `publish.yml` the `max_node_major` default moves from `22` to `26`.
