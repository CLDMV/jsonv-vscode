# jsonv-vscode v0.1.2 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

Version 0.1.2 changes how CI concurrency treats release-relevant runs. No extension code changed: the grammar, language configuration, icons and `package.json` contributions are the same as in 0.1.1.

---

## 🔧 CI & tooling

### Never supersede release-relevant CI runs ([#6](https://github.com/CLDMV/jsonv-vscode/pull/6))

The `ci.yml` concurrency group previously cancelled superseded runs on every ref except `master` and `main`. It is now derived by context: pushes to the release base branch (from the `CLDMV_RELEASE_BASE` variable, falling back to the repository's default branch), pushes to `next` and `hotfixes`, and the `next` and `hotfixes` release PRs each get a unique group per run, so none of them is cancelled. Feature branches and feature PRs still cancel superseded runs. Previously a burst of pushes during a release could cancel a pending run and leave a red cancelled check on the release PR.
