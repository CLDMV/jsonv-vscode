# jsonv-vscode v0.1.4 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

Version 0.1.4 reworks the hotfix-redirector workflow so Dependabot security PRs redirected away from `master` are cherry-picked as signed commits. Only `hotfix-redirector.yml` and the version number changed; the extension itself is untouched.

---

## 🔒 Security & supply chain

### Signed security cherry-picks ([#11](https://github.com/CLDMV/jsonv-vscode/pull/11))

`hotfix-redirector.yml` previously contained the whole redirect job inline, using the `redirect-hotfix-pr` step action. It is now a thin caller of `workflow-hotfix-redirector.yml@v4` that maps `BOT_NAME`, `BOT_EMAIL`, `BOT_GPG_PRIVATE_KEY` and `BOT_GPG_PASSPHRASE` from the `CLDMV_BOT_*` secrets and runs with `contents: write` (it previously had `contents: read`). The reusable cherry-picks the security update onto a fresh branch and pushes it signed, so redirected security PRs are no longer blocked by the signature rule.
